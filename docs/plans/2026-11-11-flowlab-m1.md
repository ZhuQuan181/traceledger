# FlowLab M1 实现计划

> **执行说明：** 按任务顺序推进；每个任务完成即 commit；不使用并发子任务。
> 约束：Python 环境一律用 `uv`；数据用**合成数据**，不碰用户真实数据集；模型先用最基础的 **MLP**。

**Goal**：把 CSV/pcap 变成统一特征，跑通 1 个 MLP + 2 个基线，产出可复现的评估报告，并有一个能看的界面。

**Architecture**：五层单向数据流 —— `ingest → features → models → eval → report/api`。层间只通过 dataclass 传值，禁止反向依赖。模型通过注册表插件化。

**Tech Stack**：Python 3.11 · uv · pandas · numpy · scikit-learn · PyYAML · pytest · FastAPI · React(Vite) · tshark（pcap 可选依赖）

---

```python
# src/flowlab/cli.py
import argparse


def build_parser() -> argparse.ArgumentParser:
    p = argparse.ArgumentParser(prog="flowlab", description="流量异常检测工作台")
    sub = p.add_subparsers(dest="cmd")
    sub.add_parser("demo", help="用合成数据跑一次完整实验")
    return p


def main(argv=None):
    args = build_parser().parse_args(argv)
    if args.cmd is None:
        build_parser().print_help()
    return 0
```

## Task 5: pcap 读取器（tshark → 流）

**Objective**：把 pcap 转成与 CSV 同 schema 的 DataFrame。

**Files**：Create `src/flowlab/ingest/pcap.py`, `tests/test_ingest_pcap.py`

**实现要点**
- 调 `tshark -r x.pcap -T fields -e frame.time_epoch -e ip.src -e ip.dst -e tcp.srcport -e tcp.dstport -e frame.len -e ip.proto`
- Python 侧按五元组 ± 超时 120s 聚合成流，算 duration/packets/bytes/pps/bps
- tshark 不存在时抛 `PcapUnavailable` 并给出安装提示（**不自动装**）
- 测试用 `tshark` 生成的 2 包 pcap，或 mock `subprocess.run`
