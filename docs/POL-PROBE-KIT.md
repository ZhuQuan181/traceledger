# PoL 探针执行包（3 天）

> 目的：验证"研究者真的会用自己的数据来跑"这件事，而不是继续堆功能。
> 对应 `06-验证实验-PoL-Probe.md`；本文件是可直接执行的材料。

## 一、假设与判定

**假设**：做流量异常检测的研究者，当前的痛点是"每次换数据集都要重写一遍预处理与评估"，而不是"缺一个模型"。

| 判定 | 阈值 | 含义 |
|---|---|---|
| 成立 | 3 天内 **≥3 人** 真的拿自己的数据跑了一次，且 **≥1 人** 主动提出"能不能支持 XX" | 需求真实，继续做 |
| 存疑 | 1–2 人跑了，但没人提后续需求 | 痛点不够强，砍功能、只保留"报告生成" |
| 不成立 | 0 人跑；或都只说"挺酷" | 停止 M3，换方向 |

**注意**：说"看起来不错"不算信号；**跑了自己的数据**才算。

bash scripts/make_probe_pack.sh          # 生成 dist/probe-pack/

## 三、邀请话术（直接复制）

**微信 / 邮件短版：**

> 我在做一个流量异常检测的实验工作台，能直接把 CSV/pcap/Zeek conn.log 跑成一份带泄漏检查和混淆矩阵的报告。
> 想请你用自己的数据试 15 分钟——主要想看你现在的流程里哪一步最烦。数据不用发我，本地跑。
> 方便的话我把试用包发你？

**当面 / 组会版：**

> 三件事：① 打开这个 HTML 看 2 分钟；② 把你的一个数据集拖进去跑一遍；③ 告诉我哪一步最麻烦。
> 我不推销工具，主要想确认"换数据集要重写预处理"这件事对你是不是真的痛。

## 四、30 分钟会话脚本

| 时间 | 做什么 | 记录什么 |
|---|---|---|
| 0–5 分钟 | 让他自己打开 `demo-report.html`，不说话 | 他第一眼看哪里？会不会点右栏泄漏检查？ |
| 5–15 分钟 | 让他跑**自己的数据** | 卡在哪：格式？标签列？装依赖？报错看不懂？ |
| 15–25 分钟 | 问他现在的流程 | 上次换数据集花了多久？最难的是哪一步？ |
| 25–30 分钟 | 看报告 | 他会拿这份报告做什么？投稿？组会？给甲方？ |

**只观察，不解释。** 他要问怎么用，反问"你觉得应该在哪"。

## 五、观察表（每人一行）

| 字段 | 记录 |
|---|---|
| 姓名/代号 | |
| 数据格式 | csv / pcap / zeek / pkl / npz / 其他 |
| 数据规模 | 行数、列数 |
| 是否跑通 | 是 / 否（卡在哪一步） |
| 首次成功耗时 | 分钟 |
| 报错是否看懂 | 是 / 否（哪句看不懂） |
| 现在的替代方案 | 自己写脚本 / CICFlowMeter + sklearn / 别人代码 |
| 原话（痛点） | 逐字记，不要转述 |
| 后续需求 | "能不能支持 XX" |
| 是否愿意再用 | 会 / 不会 / 看情况 |

## 六、失败信号与应对

| 现象 | 说明什么 | 怎么办 |
|---|---|---|
| 卡在装依赖 | 交付形态错了 | 优先做单文件 exe / Docker，而不是加功能 |
| 卡在"我的数据没有 label" | 我们把研究者想简单了 | 强化 `score` 路径与半监督 |
| 跑通了但没反馈 | 痛点不够强 | 砍功能，只留报告 |
| 只关心"能不能实时" | 定位错了 | 承认不是 IDS，转向离线复盘场景 |
| 要求"和 XXX 论文对比" | 需要一个基准库 | 做 CICIDS 基准 + 排行榜式对照 |

## 七、三天节奏

- **D1**：发出 6 份邀请（目标 3 人答应）
- **D2**：做 2–3 次 30 分钟会话，当场记录观察表
- **D3**：补 1–2 次；晚上汇总，按第一节的阈值判定

## 八、判定之后

- 成立 → 按 ICE 继续（首跑向导 → 告警解释补全 → 对比视图）
- 存疑 → 只保留"报告生成"，砍掉消融/历史/多格式
- 不成立 → 停 M3，把 `06` 的结论写进 README，转向别的方向
